# Изменения

У каждой выпущенной версии здесь есть раздел, и `release.yml` откажется
выпускать тег, для которого раздела нет. Это не формальность: релиз без записи
— релиз, который потом нельзя прочитать.

Версии по [semver](https://semver.org). Пока мажор `0`, ломающее изменение
живёт в минорной версии.

## Не выпущено

### Слой доверия

- У каждой нормы ссылка «сверить с действующей редакцией» (zakonrf.info) и
  реквизиты акта (номер ФЗ и дата) — в API (`source_url`, `act_ref`) и в UI.
- Честное «прямого ответа не нашлось» при низкой уверенности (порог
  откалиброван по реальному реранкеру); ведущая фраза-ответ вместо списка.

### Юридические задачи

- Генераторы **претензии** (`/v1/claim`) и **искового заявления**
  (`/v1/lawsuit`) из реально найденных норм.
- Калькуляторы со ссылкой на норму: **неустойка** (`/v1/penalty`, ст. 23 / 28
  ЗоЗПП), **госпошлина** (`/v1/fee`, ст. 333.19 / 333.36 НК), **проценты по
  ст. 395 ГК** (`/v1/interest`).
- **Чек-лист договора** (`/v1/contract`) — проверка существенных условий и
  рискованных пунктов по нормам.

### Корпус и демо

- В корпус добавлен **Закон о защите прав потребителей** (`corpus/zozpp.json`).
- Публичная демка на GitHub Pages: калькуляторы и чек-лист работают в браузере
  без бэкенда — [drobyshevdev.github.io/praxis/try](https://drobyshevdev.github.io/praxis/try/).

## 0.0.1

Первый срез. Отвечает на вопрос и приводит ссылки на конкретные нормы, каждую
из которых проверяет отдельно. Если подтверждения в законе нет — сообщает об
этом, а не досочиняет.

### Поиск и корпус

- Шесть кодексов и реальная судебная практика: постановления Пленума ВС РФ, а
  не образец для демонстрации.
- v0-срез работает на чистой стандартной библиотеке: ingest и BM25 без единой
  зависимости. Плотный поиск, реранкер и NLI-верификатор — тяжёлые модели,
  ставятся отдельно через экстру `ml`.
- Граф с привязкой к акту, мультивыгрузка корпуса.

### Ответ и его проверка

- Уверенность экстрактивного ответа считается по реранкеру, а не по
  NLI-вопросу.
- `praxis-eval` — golden-eval, трекаемый через mlango.
- LLM-режим — отдельный агент на glia, за экстрой `agent`. Ядро без него
  работает.

### Как запустить

- `praxis-demo`, `praxis-ask`, `praxis-eval` — три команды.
- Открытый API `/v1` за экстрой `api`: платформа для клиентов, а не только
  веб-интерфейс.
- Docker «скачал и запустил», без токенов.
- Десктоп-клиент за экстрой `desktop`.

### Чего здесь нет

Пакета на PyPI. Имя `praxis` там занято библиотекой Google из проекта PAX, и
это не спор, который стоит вести. `release.yml` собирает дистрибутивы и
прикладывает их к GitHub Release; установка — из репозитория или из релиза.
