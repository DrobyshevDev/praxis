# Praxis

> Юридический ассистент, которому можно доверять: ответы по российскому праву
> с проверяемыми ссылками на конкретные нормы — и честным «я не нашёл», когда
> подтверждения нет.
>
> *(рабочее имя — легко меняется; альтернативы: Norma, Lexara, VeriLex, Jurà)*

---

## Проблема, которую решаем

У юриста сегодня три инструмента, и каждый плох по-своему:

1. **ChatGPT / общие LLM** — выдумывают. Ссылаются на несуществующие статьи и
   дела, путают редакции, уверенно врут. Юрист физически **не может** такому
   доверять: цена ошибки — проигранное дело или дисциплинарка.
2. **КонсультантПлюс / Гарант** — это дорогой *поиск*, а не *ответ*. Находит
   документы, но синтез, сопоставление норм и вывод юрист делает руками.
3. **Google / Яндекс** — мусор, форумы, устаревшие редакции, SEO-помойки.

**Пробел ровно посередине:** нет инструмента, который даёт *ответ на вопрос* со
скоростью LLM, но с **надёжностью справочной системы** — где каждое утверждение
привязано к конкретному пункту конкретной статьи, и это можно проверить в один клик.

Именно надёжность цитат — главный failure mode всего легал-AI (Harvey, CoCounsel,
Legora воюют ровно за это). Мы делаем её ядром продукта, а не украшением.

## Для кого

- **Юристы и юрисконсульты** малого/среднего бизнеса (нет доступа к дорогим СПС).
- **Бухгалтеры и HR** — вопросы по НК, ТК, КоАП без юриста в штате.
- **ИП и основатели** — «а можно ли…», «что грозит за…», «как оформить…».
- **Физлица** — потребительские, трудовые, семейные, жилищные споры.

Международная цель — та же архитектура на EU/US-праве (EUR-Lex, CourtListener,
Caselaw Access Project — открытые данные уже есть). РФ — первый рынок, потому что
это рынок Дениса и данные по нормативке доступны.

## Что делает продукт (и чем отличается)

Вопрос на естественном языке → агент планирует поиск → гибридный retrieval по
корпусу норм → **каждое утверждение в ответе привязано к span-у источника** →
**отдельный Citation Verifier проверяет, что источник реально это подтверждает** →
ответ с кликабельными ссылками + честный флаг уверенности.

Три вещи, которых нет у «ещё одного chat-with-PDF»:

| Фича | Зачем пользователю |
|------|--------------------|
| **Citation Verifier** | Каждая ссылка проверена NLI-моделью на entailment. Если норма не подтверждает тезис — система не выдаёт его за факт. Это и есть доверие. |
| **Agentic self-RAG** | Сложный вопрос разбивается на под-запросы, агент до-ищет и самокритикует, пока не наберёт достаточно оснований (а не отвечает по первому попавшемуся чанку). |
| **Eval-харнесс + дашборд** | Faithfulness / citation-precision меряются на каждом релизе. Мы *знаем* качество, а не надеемся. |

## Честно про данные (важно)

- **Нормативка РФ — доступна отлично.** Кодексы (ГК, НК, ТК, КоАП, УК, ГПК, АПК,
  ЖК, СК…) и федеральные законы есть в машиночитаемом виде (pravo.gov.ru,
  официальное опубликование). На этом строим **v1** — уже полезно огромной
  аудитории.
- **Судебная практика РФ — сложнее.** Нет открытого структурированного корпуса
  уровня Caselaw Access Project; kad.arbitr.ru / ГАС «Правосудие» отдают данные
  тяжело (антибот, разметка). Практику подключаем в **v2** отдельным data-пайплайном.

Поэтому клин v1 — **проверяемый Q&A по действующему законодательству РФ**.
Практика и построение графа цитирований — следующий этап.

## Дорожная карта

- **v0 — Foundation.** ✅ Скелет платформы, доменные модели, легал-aware чанкинг, baseline BM25.
- **v1 — Trustworthy Q&A.** ✅ Гибридный retrieval (BM25+dense) + reranker, Citation
  Verifier (NLI), agentic self-RAG с трейсом, eval-харнесс + дашборд, FastAPI + веб-UI.
  Каждый ML-компонент pluggable: реальная модель на GPU / Claude + детерминированный офлайн-fallback.
  *Осталось на v1:* заменить образец реальным корпусом кодексов с pravo.gov.ru.
- **v2 — Судебная практика + Graph.** Data-пайплайн практики, граф «норма ↔ дела»,
  multi-hop рассуждения, «есть ли практика за/против».
- **v3 — Продуктивизация.** Аккаунты, история, экспорт с оформленными ссылками,
  мониторинг изменений редакций, международный корпус (EU/US).

Как запускать — см. [docs/DEVELOPMENT.md](docs/DEVELOPMENT.md).

## Стек и экосистема DrobyshevDev

- **Backend:** Python 3.12 + FastAPI, Postgres + pgvector, Docker.
- **Retrieval:** гибрид (BM25/FTS + плотные эмбеддинги BGE-M3), reranker bge-reranker-v2-m3.
- **LLM:** pluggable — Claude (качество) + RU-провайдеры (GigaChat/YandexGPT) для
  сценариев с требованием резидентности; локальные модели на GPU (RTX 4060) для эмбеддингов/reranker/NLI.
- **Экосистема (догфудинг своих либ):**
  - **glia** (glass-box агент-луп) — оркестрация agentic self-RAG, прозрачно и без магии.
  - **mlango** («Django для ML») — serving, eval-прогоны, drift-мониторинг качества ретривера.

Архитектура — в [ARCHITECTURE.md](ARCHITECTURE.md).
